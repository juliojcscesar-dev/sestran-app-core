# Paranavaí Trânsito Pro

Crie a ETAPA 1 do sistema web administrativo “SESTRAN — Gestão de Trânsito e Eventos” para a Prefeitura Municipal de Paranavaí/PR, conforme especificação do usuário: interface institucional moderna em pt-BR, layout responsivo prioritariamente desktop, autenticação segura, controle de acesso no backend para ADMINISTRADOR/GESTOR/OPERADOR/CONSULTA, rotas protegidas e banco relacional preparado para usuários, agentes, orientadores, solicitantes, escolas, eventos, ordens de serviço, veículos abandonados, educação no trânsito e histórico. Crie dashboard com cards e próximas atividades, menu com todos os módulos indicados e telas honestas de “disponível em breve” para módulos ainda não implementados. Inclua padrões de interface solicitados, validações frontend/backend e deixe a base pronta para a ETAPA 2 de Ordem de Serviço. Não implemente funcionalidades fictícias.
